Options:
  --help                    show all options
  --dirs arg                select directories to scan
  --disableDirs arg (=none) select directories you do not want to scan
  --depth arg (=0)          set scanning depth
  --fileSize arg (=1)       set minimal file size to scan
  --masks arg (=none)       set masks of file names allowed for comparison
  --blockSize arg (=1024)   set minimal block size to compare
  --hash arg (=crc32)       set hash algorithm (crc32 or md5)
